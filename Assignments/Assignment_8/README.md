# Logic Building Assignment 8

Marvellous Infosystems — C Programming

## Programs

1. `program8_1.c` — Classify a number as Small, Medium, or Large.
2. `program8_2.c` — Display a single digit in words.
3. `program8_3.c` — Calculate factorial of a number.
4. `program8_4.c` — Display multiplication table.
5. `program8_5.c` — Display multiplication table in reverse order.

## Compile and Run

```bash
gcc program8_1.c -o program8_1
./program8_1
```

Replace `1` with the program number (1–5). Each program accepts input from the user and uses a separate function for its logic.
