# Logic Building Assignment 10

**Language:** C  
**Institute:** Marvellous Infosystems

## Programs

| No. | File | Description | Function |
|---|---|---|---|
| 1 | `program10_1.c` | Circle Area | `CircleArea()` |
| 2 | `program10_2.c` | Rectangle Area | `RectArea()` |
| 3 | `program10_3.c` | Kilometres to Metres | `KMtoMeter()` |
| 4 | `program10_4.c` | Fahrenheit to Celsius | `FhtoCs()` |
| 5 | `program10_5.c` | Square Feet to Square Metres | `SquareMeter()` |

## Compile and Run

Each program is independent. Example:

```bash
gcc program10_1.c -o program10_1
./program10_1
```

Replace `program10_1` with the desired program filename.

## Sample Input and Expected Output

### 1. Circle Area
- Input: `5.3`
- Expected numeric result: `88.202600`

### 2. Rectangle Area
- Input: `5.3, 9.78`
- Expected numeric result: `51.834000`

### 3. Kilometres to Metres
- Input: `5`
- Expected numeric result: `5000`

### 4. Fahrenheit to Celsius
- Input: `10`
- Expected numeric result: `-12.222222`

### 5. Square Feet to Square Metres
- Input: `5`
- Expected numeric result: `0.464500`

## Notes

- Each solution uses the function signature specified in the assignment.
- Circle area uses π = 3.14 as instructed.
- Square-feet conversion uses 1 sq ft = 0.0929 sq m as instructed.
- Decimal output may differ slightly due to floating-point representation.
- The examples are based on the provided assignment sheet.
