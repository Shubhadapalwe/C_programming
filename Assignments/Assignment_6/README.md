# Logic Building Assignment 6 — C Programming

Marvellous Infosystems | Five independent C programs.

| File | Problem |
|---|---|
| `program6_1.c` | Calculate Electricity Bill |
| `program6_2.c` | Check Admission Eligibility |
| `program6_3.c` | Calculate Shopping Discount |
| `program6_4.c` | Check Triangle Validity |
| `program6_5.c` | Calculate Employee Bonus |

## Compile and run

```bash
gcc -std=c11 -Wall -Wextra program6_1.c -o program6_1
./program6_1
```

Compile each program separately by changing the filename.
