# Assignment 15 — C Logic Building

Five programs based on the supplied Marvellous Infosystems assignment screenshots.

| File | Task |
|---|---|
| program15_1.c | Read and print a full name |
| program15_2.c | Check if a number is greater than 100 |
| program15_3.c | Compare two numbers |
| program15_4.c | Multiply three numbers, ignoring zero inputs unless all are zero |
| program15_5.c | Calculate marks percentage |

Compile and run (replace filename as needed):

```sh
gcc -std=c11 -Wall -Wextra program15_1.c -o program15_1
./program15_1
```
